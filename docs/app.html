llpeek

Watch a language model write one token at a time: how sure it was, and what else it considered.

The prompt ends with a space. The space usually belongs to the next token, so a model rarely sees one here and the first step will look more hesitant than it is. Remove it unless that is what you want to test.

idle
a token the model considered but did not pick. Click it for one continuation from there. everything else it considered

Press Run. Each column will show the tokens the model weighed at that step: the tallest is the likeliest, the colored one is what it picked. Wide columns are where it hesitated.
